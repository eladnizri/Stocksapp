# שרת האפליקציה — הקמה מלאה

Worker אחד על Cloudflare עושה שני דברים:

1. **מחירים חיים** לדפדפן — `GET /q?s=SPY,QQQ`
2. **בדיקת התראות מתוזמנת** ששולחת ל-ntfy, כולל דוח 17:00 והתראות תזוזה

## למה זה צריך להתקיים

הדפדפן לא מסוגל למשוך מחירים בעצמו, ולא בגלל באג אצלנו:

- **Yahoo** לא שולח כותרת `Access-Control-Allow-Origin`, ולכן הדפדפן מסרב
  למסור את התשובה לקוד — גם כשהיא מגיעה בשלמותה.
- **Nasdaq** בדיוק אותו דבר: עונה לשרת מצוין, ולדפדפן לא נותן להקריא.
- **הפרוקסי הציבוריים** ששימשו כגשר נפלו יחד — שניים נתקעו, ו-corsproxy.io
  עבר לתשלום — והם מתחלפים בין חי למת משעה לשעה.

ובמקביל, **התזמון של GitHub** — שעליו רצו ההתראות — שתק שלושה ימים רצופים
בלי שגיאה בשום מקום, ואחר כך התייצב על ריצה אחת בערך כל ארבע שעות במקום
ארבע בשעה. התראה שמגיעה באיחור של ארבע שעות היא לא התראה.

Worker פותר את שניהם: הוא רץ בצד שרת (שם CORS לא רלוונטי), מחזיר לדפדפן
תשובה עם הכותרת הנכונה, ויש לו תזמון משלו שבאמת יורה.

# ההקמה, שלב אחר שלב

## שלב 1 — חשבון

היכנס ל-**https://dash.cloudflare.com** והירשם. חינם, בלי כרטיס אשראי.
אימות מייל, וזהו.

## שלב 2 — יצירת ה-Worker

בתפריט השמאלי: **Compute (Workers)** ← כפתור **Create** ←
**Start with Hello World!** ← תן שם, למשל `stocks` ← **Deploy**.

זה יוצר Worker ריק שכבר עובד. הכתובת שקיבלת נראית כך, ותשמש אותנו בהמשך:

```
https://stocks.<שם-המשתמש-שלך>.workers.dev
```

## שלב 3 — הדבקת הקוד

אחרי הפריסה לחץ **Edit code** (או **</> Edit code** למעלה).

מחק את **כל** מה שיש בעורך, והדבק במקומו את כל התוכן של
[`worker/quotes.js`](../worker/quotes.js) מהריפו הזה — מהשורה הראשונה עד
האחרונה. לחץ **Deploy** למעלה מימין.

בדיקה מיידית: פתח בדפדפן

```
https://stocks.<המשתמש-שלך>.workers.dev/q?s=SPY
```

אתה אמור לראות JSON עם מחיר SPY אמיתי. אם כן — החלק של המחירים גמור.

## שלב 4 — חיבור האפליקציה למחירים

באפליקציה: **גלגל ההגדרות** ← כרטיס **שרת מחירים** ← הדבק את הכתובת
(רק הבסיס, בלי `/q`) ← **שמור ובדוק**.

הכפתור לא רק שומר: הוא מושך דרך הכתובת מחיר SPY אמיתי ומראה אותו לך. אם
משהו לא תקין הוא **לא ישמור** ויגיד מה נכשל — כתובת שלא עונה גרועה יותר
מכלום, כי היא הייתה מחליפה גיבוי שכן עובד.

**עד כאן זה מספיק** אם רצית רק מחירים חיים. השלבים הבאים מעבירים גם את
ההתראות.

# העברת ההתראות ל-Cloudflare

## שלב 5 — מקום לזכרון (KV)

ההתראות חייבות לזכור מה כבר נשלח, אחרת אותה התראה תישלח כל רבע שעה כל עוד
המחיר מעל הרף. ב-GitHub זה ישב בקובץ בריפו; כאן זה יושב ב-KV.

1. בתפריט השמאלי: **Storage & Databases** ← **KV** ← **Create Instance**.
2. שם: `stocks-alerts` ← **Create**.
3. חזור ל-Worker שלך ← לשונית **Settings** ← **Bindings** ← **Add** ←
   **KV Namespace**.
4. **Variable name:** `ALERTS` ← בדיוק כך, באותיות גדולות.
   **KV namespace:** בחר את `stocks-alerts`.
5. **Deploy**.

אם ה-binding חסר, ה-Worker **לא ישלח כלום** בכוונה, ויגיד את זה ב-`/health`.
התראה שחוזרת כל רבע שעה גרועה יותר מהתראה שלא הגיעה.

## שלב 6 — הנושא של ntfy, כסוד

1. ב-Worker ← **Settings** ← **Variables and Secrets** ← **Add**.
2. **Type:** `Secret` (לא Text — סוד לא מוצג שוב אחרי השמירה).
3. **Name:** `NTFY_TOPIC`
4. **Value:** אותו נושא ntfy שכבר מוגדר לך ב-GitHub Secrets ובאפליקציה בטלפון.
5. **Deploy**.

הנושא הוא סוד משותף: מי שיודע אותו יכול גם לקרוא את ההתראות שלך וגם לשלוח
אליך. לכן הוא נכנס כ-Secret ולא נכתב בקוד לעולם.

## שלב 7 — התזמון

ב-Worker ← **Settings** ← **Trigger Events** ← **Add** ← **Cron Trigger**:

```
*/15 13-21 * * 1-5
```

כל רבע שעה, 13:00–21:59 UTC, ימים שני עד שישי. זה מכסה את שעות המסחר
האמריקאיות גם בקיץ (13:30–20:00 UTC) וגם בחורף (14:30–21:00), וגם את
שעת הדוח (17:00 בישראל = 14:00 UTC בקיץ, 15:00 בחורף). **Deploy**.

**חשוב — הסדר:** ברגע שהתזמון הזה קיים, ה-Worker מתחיל לשלוח. GitHub עדיין
שולח גם הוא, ותקבל כל התראה פעמיים. לכן מיד אחרי שווידאת בשלב 8 שההתראה
מה-Worker באמת הגיעה, כבה את GitHub: `Settings` → `Secrets and variables` →
`Actions` → `Variables` → `New variable` → `ALERTS_OWNER` = `cloudflare`.

## שלב 8 — לוודא שזה באמת עובד

שלוש כתובות, בסדר הזה:

**א.** `https://stocks.<המשתמש>.workers.dev/health`

```json
{ "ok": true, "kv": true, "ntfyTopic": true, "israelTime": "2026-09-01 17:05" }
```

`kv` ו-`ntfyTopic` חייבים להיות `true`. אם אחד מהם `false`, שלב 5 או 6 לא
הושלם. הסוד עצמו לא מוחזר — רק אם הוא קיים.

**ב.** `https://stocks.<המשתמש>.workers.dev/alerts?dry=1`

מריץ את הבדיקה האמיתית ומחזיר בדיוק מה **היה** נשלח — בלי לשלוח ובלי לשמור.
כאן תראה כמה התראות נטענו, אילו סימבולים תומחרו, ומה היה נורה.

**ג.** `https://stocks.<המשתמש>.workers.dev/alerts?ping=1`

שולח התראת בדיקה אחת אמיתית לטלפון. אם היא הגיעה — הכל מחובר.
מוגבל להודעה אחת לעשר דקות, כי הכתובת ציבורית ומי שיודע אותה לא אמור
להיות מסוגל להציף לך את הטלפון.

## מה השתנה בצד של GitHub

ה-workflow `alerts.yml` **כבר לא שולח התראות בתזמון**. שני מתזמנים עם שתי
זכרונות נפרדים היו שולחים כל דבר פעמיים.

מה שנשאר לו: רענון `data/tickers.json` — קובץ הגיבוי שהאפליקציה קוראת כשאין
שרת מוגדר או כשהוא נופל. קובץ כזה יכול לפגר בלי שאף אחד ייפגע, וזו בדיוק
העבודה שמתזמן לא אמין עדיין מסוגל להחזיק.

בדיקת ההתראות עצמה נשארה זמינה שם ב-**Run workflow** ידני, כולל `--probe`,
כדי שאפשר יהיה לבדוק בלי להתנגש ב-Worker.

## מה זה נותן

| | לפני | אחרי |
|---|---|---|
| מדדים בבית | קובץ שנבנה כל ~15 דק׳ (כשהתזמון רץ) | חי, בכל רענון |
| רשימת מעקב ועסקאות | אותו קובץ | חי |
| ניתוח מניה בודדת | פרוקסי ציבורי — שבור | חי |
| VIX ודולר/שקל | אין מקור בכלל | חי |
| התראות מחיר | תזמון שירה פעם ב-4 שעות | כל 15 דק׳, אמין |
| דוח 17:00 | לרוב פספס את החלון | יורה בחלון |
| תלות ב-cron של GitHub | מלאה | רק לקובץ הגיבוי |

## עלות ומגבלות

- החינמי של Cloudflare: **100,000 בקשות ליום**, ו-**1,000 כתיבות KV ליום**.
  השימוש כאן מגיע לכמה מאות בקשות ו-32 כתיבות ביום לכל היותר.
- ה-Worker שומר תשובת מחירים במטמון ל-20 שניות, כך שריענון תכוף או כמה
  מכשירים לא מכפילים פניות למקור.
- עד 25 סימבולים בבקשת מחירים; האפליקציה מפצלת לבד אם יש יותר.
- בריצה המתוזמנת יש תקציב של 44 פניות החוצה (מגבלת Cloudflare היא 50). הסדר
  הוא התראות ← פוזיציות ← SPY/QQQ ← רשימת מעקב, כך שאם רשימת המעקב ארוכה
  מאוד, מה שנופל בסוף הוא הפחות קריטי — ולא משהו אקראי.

## אבטחה

ה-Worker **אינו** פרוקסי פתוח. הוא מקבל סימבולים בלבד, לעולם לא כתובות, וכל
סימבול מסונן לתווים שטיקר יכול להכיל. אין קלט שיגרום לו למשוך משהו מלבד
Yahoo, Nasdaq, `data/alerts.json` שלך ו-ntfy — נבדק בבדיקות
(`worker_test.mjs`) שמנסות להזריק גם נתיב וגם כתובת מלאה.

`NTFY_TOPIC` נשמר כ-Secret ולא מוחזר בשום תשובה, כולל `/health`.

## אם לא מקימים

האפליקציה ממשיכה לעבוד: מחירים מהקובץ בריפו, ומה שהפרוקסי הציבוריים
מצליחים לתת. ההתראות, לעומת זאת, כבר לא רצות בתזמון של GitHub — אם החלטת
לא להקים את ה-Worker, החזר את הריצה המתוזמנת ב-`alerts.yml` על ידי הסרת
השורה `if: ${{ github.event_name == 'workflow_dispatch' }}` משלב
"Check alerts".
